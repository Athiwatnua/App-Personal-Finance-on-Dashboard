# Personal Finance on Dashboard

เว็บบันทึกรายรับรายจ่ายแบบ manual พร้อมเก็บข้อมูลหลักเป็น JSON ในโปรเจกต์

## เริ่มใช้งาน

บน Windows ให้ดับเบิลคลิก `start.bat` หรือเปิด terminal ในโฟลเดอร์นี้แล้วรัน `node server.js` จากนั้นเปิด [http://127.0.0.1:4173](http://127.0.0.1:4173) ในเบราว์เซอร์ ต้องเปิดผ่านเซิร์ฟเวอร์นี้เพื่อให้หน้าเว็บอ่านและเขียนไฟล์ JSON ได้ การเปิด `index.html` โดยตรงจะไม่สามารถบันทึกข้อมูลไปยังโฟลเดอร์โปรเจกต์ได้

## ไฟล์ข้อมูล

ข้อมูลหลักอยู่ที่ `data/finance.json` โดยมีรายรับประจำ รายการหัก และรายจ่ายทั้งหมด การเพิ่ม แก้ไข หรือลบข้อมูลจากหน้าเว็บจะบันทึกกลับไฟล์นี้ทันที ส่วน `localStorage` ใช้เก็บสำเนาสำรองในเบราว์เซอร์เท่านั้น

เมนู **Export data** ดาวน์โหลดไฟล์ JSON ปัจจุบัน ส่วน **Import data** เลือกไฟล์ JSON schema version 1 แล้วนำข้อมูลเข้าแทนข้อมูลปัจจุบัน พร้อมเขียนลง `data/finance.json` ใช้ไฟล์ตัวอย่างในโฟลเดอร์ `data` เป็นแม่แบบได้

```json
{
  "version": 1,
  "income": { "name": "เงินเดือน", "amount": 30000 },
  "deductions": [{ "id": "deduction-1", "name": "ประกันสังคม", "amount": 750 }],
  "expenses": [{
    "id": "expense-1", "title": "ค่าเดินทาง", "amount": 120,
    "category": "เดินทาง", "date": "2026-11-17", "note": ""
  }]
}
```

## Dashboard

เลือกเดือนจากตัวกรองด้านบน แล้วเปิด **My Finance Dashboard** เพื่อดูรายรับรวม รายการหัก รายรับสุทธิ และยอดคงเหลือของเดือนนั้น กราฟแท่งแสดงยอดรายจ่ายรายวันโดยแบ่งสีตามหมวดหมู่ ส่วนกราฟเส้นซ้อนทับแสดงยอดคงเหลือสะสมปลายวัน

เซิร์ฟเวอร์ใช้ Node.js built-in modules เท่านั้นและ bind เฉพาะ `127.0.0.1` ไม่มีข้อมูลถูกส่งไปบริการภายนอก
