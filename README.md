# Personal Finance on Dashboard

เว็บแอปสำหรับจดรายรับและรายจ่ายด้วยตนเอง ใช้ติดตามการเงินส่วนบุคคลระหว่างพัฒนา PFT ข้อมูลเก็บเป็นไฟล์ JSON ในเครื่อง ไม่ต้องสมัครบัญชี และไม่มีการส่งข้อมูลไปบริการภายนอก

## ภาพรวมแอป

- **My Finance Record** ใช้ตั้งค่ารายรับประจำและรายการหัก เช่น ประกันสังคม พร้อมเพิ่ม แก้ไข หรือลบรายจ่ายที่ระบุหมวดหมู่ วันที่ และหมายเหตุได้
- **My Finance Dashboard** ใช้เลือกเดือนเพื่อดูรายรับรวม รายการหัก รายรับสุทธิ รายจ่าย และยอดคงเหลือ พร้อมกราฟแท่งรายจ่ายรายวันแยกสีตามหมวดหมู่ และกราฟเส้นยอดคงเหลือสะสมในแต่ละวัน
- **Database** รวมเมนูนำเข้าและส่งออกข้อมูล JSON

## เริ่มใช้งาน

บน Windows ดับเบิลคลิก `start.bat` หรือเปิด terminal ในโฟลเดอร์แอปแล้วรัน:

```bash
node server.js
```

จากนั้นเปิด <http://127.0.0.1:4173> ในเบราว์เซอร์ ต้องเปิดผ่านที่อยู่นี้เพื่อให้เว็บอ่านและเขียนไฟล์ในโฟลเดอร์โปรเจกต์ได้ การเปิด `index.html` โดยตรงจะไม่สามารถบันทึกข้อมูลลงไฟล์ได้

## การจัดเก็บและย้ายข้อมูล

ข้อมูลหลักอยู่ที่ `data/finance.json` ทุกครั้งที่เพิ่ม แก้ไข หรือลบรายรับ รายการหัก หรือรายจ่าย เว็บจะบันทึกลงไฟล์นี้ ส่วนสำเนาในเบราว์เซอร์ใช้ช่วยกู้คืนเมื่อเปิดหน้าเว็บไม่ได้เท่านั้น

เปิด **Database** ในแถบเมนูด้านซ้าย:

- **Export data** เปิดหน้าต่างให้ตั้งชื่อไฟล์และเลือกตำแหน่งบันทึกสำเนา JSON
- **Import data** เลือกไฟล์ JSON ที่ส่งออกไว้ เพื่อนำข้อมูลเข้ามาแทนข้อมูลปัจจุบันใน `data/finance.json`

ไฟล์นำเข้าต้องเป็น JSON schema version 1 ตัวอย่าง:

```json
{
  "version": 1,
  "income": { "name": "เงินเดือน", "amount": 30000 },
  "deductions": [
    { "id": "deduction-1", "name": "ประกันสังคม", "amount": 750 }
  ],
  "expenses": [
    {
      "id": "expense-1",
      "title": "ค่าเดินทาง",
      "amount": 120,
      "category": "เดินทาง",
      "date": "2026-11-17",
      "note": ""
    }
  ]
}
```

เซิร์ฟเวอร์ใช้ Node.js ที่ติดตั้งอยู่แล้ว ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม และเปิดให้เข้าถึงเฉพาะเครื่องนี้ (`127.0.0.1`)
