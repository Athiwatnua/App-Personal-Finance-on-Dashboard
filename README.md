# Personal Finance on Dashboard

เว็บแอปสำหรับจดรายรับและรายจ่ายด้วยตนเอง ใช้ติดตามการเงินส่วนบุคคลระหว่างพัฒนา PFT ข้อมูลเก็บเป็นไฟล์ JSON ในเครื่อง ไม่ต้องสมัครบัญชี และไม่มีการส่งข้อมูลไปบริการภายนอก

## ภาพรวมแอป

- **My Finance Record** ใช้ตั้งค่ารายรับประจำและรายการหัก เช่น ประกันสังคม พร้อมเพิ่ม แก้ไข หรือลบรายจ่ายด้วยการเลือกหมวดหมู่ ระบุจำนวนเงิน วันที่ และหมายเหตุ (ไม่บังคับ)
- **My Finance Dashboard** ใช้เลือกเดือนเพื่อดูรายรับรวม รายการหัก รายรับสุทธิ รายจ่าย และยอดคงเหลือ พร้อมกราฟแท่งรายจ่ายรายวันแยกสีตามหมวดหมู่ และกราฟเส้นยอดคงเหลือสะสมซึ่งไล่จากเขียวที่รายรับสุทธิ 100% ไปเหลืองที่ 50% และแดงที่ 0%
- **My Profile** แยกชุดข้อมูลแต่ละโปรไฟล์และเปลี่ยนชื่อได้ การนำเข้า JSON จะสร้างโปรไฟล์ใหม่โดยไม่เขียนทับโปรไฟล์เดิม
- **Database** รวมเมนูนำเข้าและส่งออกข้อมูล JSON

## เริ่มใช้งาน

บน Windows ดับเบิลคลิก `start.bat` หรือเปิด terminal ในโฟลเดอร์แอปแล้วรัน:

```bash
node server.js
```

จากนั้นเปิด <http://127.0.0.1:4173> ในเบราว์เซอร์ ต้องเปิดผ่านที่อยู่นี้เพื่อให้เว็บอ่านและเขียนไฟล์ในโฟลเดอร์โปรเจกต์ได้ การเปิด `index.html` โดยตรงจะไม่สามารถบันทึกข้อมูลลงไฟล์ได้

## การจัดเก็บและย้ายข้อมูล

ข้อมูลของโปรไฟล์เริ่มต้นอยู่ที่ `data/finance.json` ส่วนโปรไฟล์ที่นำเข้าใหม่จะเก็บแยกเป็นไฟล์ JSON ใน `data/` และมีรายการโปรไฟล์ใน `data/profiles.json` ทุกครั้งที่เพิ่ม แก้ไข หรือลบข้อมูล เว็บจะบันทึกลงไฟล์ของโปรไฟล์ที่เลือกอยู่

เปิด **Database** ในแถบเมนูด้านซ้าย:

- **Export data** อ่านข้อมูลล่าสุดทั้งหมดจากโปรไฟล์ที่เลือก แล้วดาวน์โหลดสำเนา JSON ชื่อ `personal-finance-<ชื่อโปรไฟล์>-<YYYY-MM-DD>.json` ซึ่งรวมรายรับ รายการหัก และรายจ่ายทั้งหมด
- **Import data** เลือกไฟล์ JSON ที่ส่งออกไว้ เพื่อสร้างโปรไฟล์ใหม่จากไฟล์นั้น แล้วสลับมาใช้โปรไฟล์ใหม่ทันที

ไฟล์นำเข้าต้องเป็น JSON schema version 1 ตัวอย่าง:

```json
{
  "version": 1,
  "income": { "name": "เงินเดือน", "amount": 10000 },
  "deductions": [
    { "id": "deduction-1", "name": "ประกันสังคม", "amount": 750 }
  ],
  "expenses": [
    {
      "id": "expense-1",
      "title": "ค่าเดินทาง",
      "amount": 120,
      "category": "เดินทาง",
      "date": "2026-11-17",
      "note": ""
    }
  ]
}
```

เซิร์ฟเวอร์ใช้ Node.js ที่ติดตั้งอยู่แล้ว ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม และเปิดให้เข้าถึงเฉพาะเครื่องนี้ (`127.0.0.1`)
